# Uruvam

Uruvam is an open-source, visual-first macOS app for creating high-fidelity product interface prototypes with OpenCode Go.

The app is planned around Electron, OpenCode v2, Vite, React, TypeScript, pnpm, and source-owned shadcn components. Generated code is the source of truth, while Uruvam itself remains a no-code visual workspace.

See [docs/PLAN.md](docs/PLAN.md) for the decision-complete product and implementation plan.

## Status

Public-alpha implementation is starting. Apple Silicon macOS is the first supported platform.
